## Open problems

- **Carousel overlaps on the TV.** Likely cause: flex `gap` is unsupported in
  Chromium 69 (shipped in 84); the harness uses a modern engine and cannot see
  it. Next step is margins instead of gap, then a device check; do not trust
  the harness alone again.
- **`com.samsung.tv.airplay-app` still runs** though its package is disabled —
  its unit starts the binary directly. Same class as NFC: needs `unitstate`.
- **ACR daemons still run** for the same reason; the package disable only

  `contents-recognition-service.service`.
- Whether `tizen.tvwindow` source composition actually shows the picture is
  unverified.
- Multi-app packages disabled as a batch still need a per-feature sanity look
  on the TV.

## Recovery

1. **Re-enable a package:** `pkgstate enable <package-id>` (from
   `/opt/usr/share/tvroot/pkgstate`, content-invoked).
2. **Reinstall a removed wgt:** store search by name; renamed IDs are listed
   as names in `docs/app-classification-2026-11-05.md`. `adplatform` also has
   a file copy under `/opt/usr/share/tvroot/uninstall-backup/`.
3. **Root lost / sdbd wedged:** power-cycle; the app and agent restart from
   boot. If the app is down, launch `.Main` via
   `POST :8001/api/v2/applications/tiz0wnprob.Main`.
4. **GUI recovery:** Apps → `12345` → set Host PC IP to the Mac address, then
   power-cycle.

## Access rules
